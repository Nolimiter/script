# KeyCRM Template Helper

> Userscript для платформи KeyCRM, що надає швидкий доступ до привітань та шаблонів повідомлень з підтримкою транслітерації імен.

## 📋 Опис

KeyCRM Template Helper - це userscript, який додає зручні кнопки для:
- Автоматичної вставки персоналізованих привітань
- Управління шаблонами повідомлень
- Транслітерації імен з латиниці на кирилицю
- Імпорту/експорту шаблонів

## ✨ Основні функції

### 🤝 Привітання з автоматичним розпізнаванням імені
- Автоматично розпізнає ім'я клієнта з інтерфейсу KeyCRM
- Транслітерує латинські імена в кириличні за допомогою вбудованого словника
- Пропонує варіанти дій, якщо ім'я невідоме

### 📝 Система управління шаблонами
- Створення, редагування та видалення шаблонів
- Організація шаблонів за категоріями
- Зміна порядку шаблонів перетягуванням (drag & drop)
- Фільтрація за категоріями

### 💾 Імпорт/Експорт
- Експорт шаблонів у форматі JSON
- Імпорт з JSON та TXT файлів
- Автоматичне створення резервних копій перед імпортом

### ⌨️ Гарячі клавіші
- `Ctrl + Alt + T` - відкриття панелі шаблонів
- Довге натискання на кнопку привітання - додавання нової транслітерації

## 🚀 Встановлення

### Крок 1: Встановіть менеджер userscripts

Оберіть один з наступних менеджерів:
- [Tampermonkey](https://www.tampermonkey.net/) (рекомендовано)
- [Violentmonkey](https://violentmonkey.github.io/)
- [Greasemonkey](https://www.greasespot.net/) (тільки Firefox)

### Крок 2: Встановіть скрипт

1. Відкрийте файл `keycrm-template-helper.user.js`
2. Скопіюйте вміст файлу
3. У менеджері userscripts створіть новий скрипт
4. Вставте скопійований код
5. Збережіть скрипт

## 🎯 Використання

### Вставка привітання

1. Відкрийте чат з клієнтом у KeyCRM
2. Натисніть на кнопку **+** (блакитна) біля поля вводу
3. Скрипт автоматично розпізнає ім'я та вставить привітання

### Робота з шаблонами

#### Відкриття панелі шаблонів
- Натисніть кнопку **≡** (зелена) біля поля вводу
- Або використайте комбінацію `Ctrl + Alt + T`

#### Використання шаблону
Просто клікніть на потрібний шаблон у списку.

#### Додавання нового шаблону
1. Відкрийте панель шаблонів
2. Натисніть кнопку **Додати**
3. Заповніть поля та збережіть

## ⚙️ Налаштування

Відкрийте файл скрипту та знайдіть блок `SettingsModule`:

```javascript
const SettingsModule = {
    myName: 'Юрій',
    messageTemplate: 'Вітаю, _! Мене звуть _, служба підтримки KeyCRM😊',
    // ... інші налаштування
};
```

## 📚 Структура модулів

- **SettingsModule** - налаштування та константи
- **StylesModule** - стилі інтерфейсу
- **UtilsModule** - допоміжні функції
- **TranslitModule** - транслітерація імен
- **TemplatesModule** - управління шаблонами
- **UIModule** - інтерфейс користувача
- **GreetingModule** - обробка привітань
- **ButtonModule** - створення кнопок
- **KeyboardModule** - гарячі клавіші
- **ObserverModule** - відстеження змін DOM

## 🐛 Усунення несправностей

### Кнопки не з'являються
1. Перезавантажте сторінку
2. Переконайтеся, що скрипт активний
3. Перевірте консоль браузера (F12)

### Шаблони не зберігаються
1. Перевірте дозволи скрипту
2. Очистіть кеш браузера
3. Спробуйте експорт/імпорт
